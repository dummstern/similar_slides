\subsection{Mögliche Abstriche}
Eine mögliche Maßnahme zur Aufwandsreduktion ist das Weglassen der Unterrepos für Mitarbeitende. Dies ist ein Feature, das gut in einer Erweiterung und bei erfolgreicher Adoption hinzugefügt werden kann.
\noindent Anfänglich wäre es denkbar das Produkt nur auf den Lehrbetrieb des Dozierenden auszurichten.

\subsection{Inkrementelle Arbeit}
Ein möglicher Ansatz für Inkrementelles Arbeiten würde die einelnen Features wie folgt sortieren:

\begin{enumerate}
    \item Das Auslesen und analysieren von Inhalten aus einer .pptx-Datei
    \item Das Vergleichen der Inhalte von zwei unterschiedlichen .pptx-Datein anhand bestimmter Metriken
    \item Das Hinzufügen und Abrufen von Präsentationen aus einem externen Repository
    \item Eine Hierarchie der Dateien nach erkannten Unterschieden schaffen.
    \item Die enge Einbindung des Programms in PowerPoint implementieren
    \item Ein intuitives UI und \textit{polish}
\end{enumerate}
